# Admin UI

The Admin UI context provides authenticated operators with management screens and Agent conversation workspaces.

## Language

**Chat Workspace**:
The screen where an operator selects a Chat Session, exchanges Messages with its Agent, and views that Agent's information.
_Avoid_: Chat room, console

**Draft Session**:
An unpersisted intention to start a new Chat Session. It becomes a Chat Session when the first Message is sent.
_Avoid_: Empty session, temporary conversation
