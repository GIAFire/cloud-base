# AI Friend UI

AI Friend（心屿）面向用户提供角色发现和 AI 陪伴对话体验。

## Language

**角色（Agent）**:
用户可以发现、收藏并选择对话的虚构成年 AI 陪伴对象，对应 Agent Runtime 中的 Agent。
_Avoid_: 真人主播、真实交友对象

**对话（Chat Session）**:
用户与一个角色之间持续的交流，其角色在对话开始后不改变。
_Avoid_: 群聊、视频动态

**消息（Message）**:
对话中的一条完整用户输入或角色回复。
_Avoid_: 流式片段、视频留言

**演示身份**:
用于体验应用流程的虚构用户身份，不代表真实会员的认证结果。
_Avoid_: 已认证会员、真实账号

**视频流**:
供用户逐条浏览角色动态、关注角色并进行点赞、收藏和留言的内容集合。
_Avoid_: 视频通话、对话

**视频邀请**:
对话中发起与当前角色进行视频交流的邀请。
_Avoid_: 视频流、视频动态
