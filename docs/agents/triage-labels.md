# Triage 标签

工程技能使用五种标准 triage 角色。本文件将这些角色映射到本仓库本地议题的 `Status:` 值。

| 标准角色 | 本仓库状态值 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由自主代理实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某种 triage 角色时，使用表中对应的本仓库状态值。
