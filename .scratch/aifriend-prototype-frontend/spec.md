# AI Friend 原型前端

Status: ready-for-agent
Implementation: completed

## Goal

以 `ui/ui-AiFriend-uniapp/demo.html` 为原型，在 `ui/ui-AiFriend-uniapp` 中完成采用 Vue 分层架构的前端应用。本阶段先完成前端，接口后续对接。

## Confirmed decisions

- 交付终端为桌面浏览器与手机 H5。
- 提供可交互演示，使用模拟数据并在本地保存。
- 为后续接入真实接口保留替换位置。
- 沿用 uni-app + Vue 3 + Pinia。
- 覆盖原型全部页面：角色发现与详情、对话列表与聊天、视频流、个人中心、登录、注册、重置密码。
- 聊天使用预设回复；视频页使用原型封面流及互动；视频邀请为明确的演示界面。真实大模型、语音、视频播放及通话后续对接。
- 访客可浏览，聊天、收藏等互动前引导模拟登录；不发送真实验证码、不保存密码。

## Confirmed implementation rules

- 保留原型“心屿”品牌、深色粉色视觉、角色内容和主要布局。桌面侧栏、手机底部导航；认证桌面双栏、手机表单；视频桌面居中、手机纵向全屏。
- 页面负责展示和交互，公共组件复用布局与控件，Pinia 管理跨页面状态，业务服务封装流程，repository 隔离模拟数据与本地存储。已有真实 API/request 保留作后续接入入口；本阶段默认演示不调用后端。
- 使用一组演示身份；登录/注册只演示流程，不建立真实账号或保存密码；验证码沿用原型的 123456。模拟登录状态跨刷新保留。
- 聊天、角色收藏、视频点赞/收藏/关注/留言和陪伴偏好均跨刷新保留；本阶段使用同一份演示数据，不提供多账号隔离。
- 退出登录只退出身份，保留演示数据；清除体验数据需二次确认，清除本应用演示数据与演示身份并返回访客状态，不影响其他应用的数据。
- 搜索、筛选、角色详情和视频浏览对访客开放；聊天、收藏、点赞、关注、留言、偏好保存需模拟登录。
- 登录成功返回原页面并恢复待完成意图；发送消息、发布留言仍需用户再次确认，输入草稿保留。取消登录回到原页面。
- 陪伴偏好影响模拟回复风格；记忆和 Plus 保留原型说明及预约演示，不生成真实长期记忆或订阅。
- 验收包含 H5 生产构建、桌面与手机宽度的实际浏览器检查、主要交互和刷新持久化验证。

## Prototype facts

- 原型品牌为“心屿”，主导航为首页、对话、视频、我的；另含角色详情、登录、注册、重置密码和视频邀请演示。
- 原型最后生效的视频页是竖向动态封面流，包含推荐/关注、点赞、收藏、留言和跳转角色/聊天。
- 原型允许访客互动，模拟登录只影响个人中心的身份展示；模拟登录状态不跨刷新保存，密码不保存。
- 原型收藏、陪伴偏好、视频关注/点赞/收藏使用本地存储；聊天及视频留言仅保存在内存。
- 原型隐私清除未覆盖视频流数据；本阶段需要明确统一的数据清除边界。
