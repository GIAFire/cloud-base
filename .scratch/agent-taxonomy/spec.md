# Agent 分类与标签

Status: ready-for-agent

## Goal

为租户内的 Agent 提供完整的分类与标签管理、绑定、展示和筛选能力。

## Domain decisions

- Agent Category 是租户级、平铺、粗粒度的导航分类。
- Agent Tag 是租户级、细粒度的描述性标签。
- 一个 Agent 可绑定零到多个分类和零到多个标签；两种关系均为多对多。
- 分类与标签只用于组织、展示和筛选，不参与 Agent 授权。
- 禁用项不可再建立新绑定，但保留并展示已有绑定，不影响 Agent 使用。
- 已被 Agent 使用的分类或标签不可删除；解绑后使用软删除。
- 分类、标签名称在租户内唯一；标签不保留额外的 `code` 身份。
- 筛选在同一维度内采用 OR，分类和标签两个维度之间采用 AND。

## Delivery scope

- 修正初始化 SQL 的租户、审计、状态、唯一性与关联模型。
- 后端提供分类和标签 CRUD、启用项选择接口及独立权限。
- Agent 创建和更新以完整集合方式事务性替换分类、标签绑定。
- Agent 详情和分页返回分类、标签摘要，并支持多值筛选。
- 前端提供分类和标签管理页、Agent 表单多选、标签快捷创建、列表筛选与展示、聊天详情展示。
- 分类只能从独立管理页创建；标签快捷创建仍受 `agent:tag:create` 权限控制。

## Lifecycle and consistency

- 关联关系采用硬删除，词表实体采用逻辑删除。
- 删除 Agent 时清理其分类、标签关联。
- 分类、标签及关联必须保持同租户，应用服务在事务内校验。
- 状态使用项目公共枚举：`0` 启用、`1` 禁用。
